# TOM Examples

This directory contains examples and demos for the Terminal Object Model (TOM) library.

## Core Examples

- **hello-world.ts** - Simple "Hello World" with basic TOM usage
- **flexbox-demo.ts** - Advanced flexbox layout demonstration  
- **rich-text-demo.ts** - Rich text with mixed inline content
- **keyboard-navigation-demo.ts** - Keyboard input and navigation
- **inline-block-test.ts** - Inline-block element positioning test
- **animated-demo.ts** - Animation and dynamic content
- **basic-demo.ts** - Basic container and styling

## Directory Structure

- **debug/** - Debug files, tests, and development utilities
- **archive/** - Historical versions and obsolete examples

## Running Examples

Use Bun to run any example:

```bash
bun run hello-world.ts
bun run flexbox-demo.ts
bun run rich-text-demo.ts
```

Press Ctrl+C or Escape to exit most examples.
